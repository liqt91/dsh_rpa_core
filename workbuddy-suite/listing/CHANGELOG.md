# 更新记录

## 1.0.0 — 2026-10-28

首个可上架版本。三件套：

**编辑窗口（PPX）**
- 打开 / 保存 / 校验，保留原文件的编码（UTF-8 + BOM）与换行风格（LF / CRLF）
- 编辑器手感：原生光标与选区、撤销重做（连续输入合并为一步）、成对补全、括号内回车展开、
  Tab / Shift+Tab 多行缩进、Ctrl+/ 注释、Ctrl+D 复制行、Alt+↑↓ 移动行、Ctrl+Shift+K 删除行、
  Ctrl+F 查找（含计数与循环跳转）、Ctrl+G 跳行、拖动滚动同步行号
- 中文输入法：组合输入期间交出原生文本渲染，一次上屏 = 一步撤销
- JSON 语法实时定位到行/列；可选用仓库内工作流模型做深度校验
- Agent 请求横幅：有未保存改动时不静默覆盖，由用户决定丢弃或稍后
- 深色窗口标题栏（Windows 11 DWM），窗口关闭时停止轮询，不留 RPC 报错

**技能（WorkBuddy Skill）**
- `open --wait` / `wait` / `capture` / `status` / `doctor` / `gui`
- 长轮询，不空转；超时返回明确退出码
- 会话离线时给出降级路径，不伪造「用户已确认」

**浏览器扩展（MV3）**
- 按需注入拾取器；高亮跟随、Esc 取消、点击即发送
- 选择器优先级：`id` → `data-testid` 等语义属性 → 人写类名 → `nth-of-type` 路径（至少两级）
- 重复 `id` 不硬用；Shadow DOM 如实标记；候选方案一并上报
- 弹窗显示会话状态，Agent 等待时徽标变黄

已知限制见 `listing/LISTING.md` 第八节。
