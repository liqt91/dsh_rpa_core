# 隐私政策 · WorkBuddy Studio

生效日期：2026-10-28 · 版本 1.0.0

## 一句话

三件套不联网、不建账号、不上传任何内容；所有数据都留在你自己的电脑上。

## 我们收集什么

**不收集。** 具体到每个组件：

| 组件 | 网络行为 | 本地存储 |
|---|---|---|
| 技能（`scripts/studio.py`） | 只监听并访问 `127.0.0.1` 上的本地会话服务 | `%TEMP%\workbuddy-studio\` 下的 `endpoint.json`、`events.jsonl`（运行日志） |
| 编辑窗口 | 只通过进程内 RPC 与本机会话通信；不发起任何外部请求 | 最近打开的文件路径（本机 `%TEMP%`），会话端点信息 |
| 浏览器扩展 | 只 `fetch` 到 `http://127.0.0.1:*`；不请求任何公网域名 | 端口号、最近 8 条拾取记录（`chrome.storage.local`） |

## 浏览器扩展会看到什么

只有在**你主动点击**「开始拾取元素」之后，扩展才会向当前标签页注入拾取脚本，并且：

- 只读取你**单击的那一个元素**的属性：选择器、标签名、可见文本（最多 120 字）、
  属性值（如 `id`、`name`、`placeholder`）、尺寸、所在页面 URL；
- 不读取页面正文、不读取表单里已填的内容、不截图、不上传 DOM；
- 单击之后立即退出拾取模式，脚本不再监听任何事件。

## 数据去哪了

拾取结果与保存事件都只写进本机回环地址 `127.0.0.1` 上的会话服务，供你正在使用的
WorkBuddy Agent 读取。**没有任何数据离开本机。**

## 你的控制权

- 关闭会话服务（`python scripts/studio.py stop`）后，三个组件之间不再有任何通信。
- 删除 `%TEMP%\workbuddy-studio\` 目录即清除全部本地记录。
- 在扩展页点「清空」可删除最近拾取记录；移除扩展即删除其全部本地数据。
- 编辑窗口不会保存你未按 Ctrl+S 的改动（关闭窗口即丢弃）。

## 第三方

无。不接入统计 SDK、崩溃上报、广告或任何第三方服务。
