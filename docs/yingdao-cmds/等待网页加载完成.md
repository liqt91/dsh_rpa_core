# 等待网页加载完成

等待网页加载完成
💡

在指定的时间内，等待网页加载完成

🎬 视频课程：影刀RPA中级课程： 网页自动化-进阶

网页对象

选择一个之前通过【打开网页】或【获取已打开的网页对象】指令创建的网页对象

加载超时时间

等待网页加载完成的超时时间，若指令执行报错"等待页面加载超时"可适当延长

加载超时后执行

当等待时间超过加载超时时间后，执行「错误处理」或停止网页加载

注：【等待网页加载完成】主要是用于页面执行某个操作后导致整个页面自动刷新重新加载

使用示例

此流程执行逻辑：打开影刀官网 --> 执行【键盘输入】指令输入{F5}刷新页面 --> 使用【等待网页加载完成】指令 --> 执行【打印日志】指令打印网页加载完成
