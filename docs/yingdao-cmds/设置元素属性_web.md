网页对象

选择一个之前通过【打开网页】或【获取已打开的网页对象】指令创建的网页对象

操作目标

从「元素库」中选择一个已捕获的元素或通过「捕获新元素」来捕获新的网页元素作为操作目标

属性名称

元素待修改的属性名称，如："style"属性可用于确定元素在网页上的样式

属性值

元素待修改的属性名称将要修改成的值，如：style = "display:None"可将元素隐藏

等待元素存在(s)

等待目标元素存在的超时时间

使用示例

此流程执行逻辑：打开影刀官网网页 --> 使用【设置元素值(web)】指令设置指定元素的style属性值为"display:None"，即隐藏该元素
