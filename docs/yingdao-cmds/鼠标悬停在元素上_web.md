# 鼠标悬停在元素上(web)

鼠标悬停在元素上(web)
💡

将鼠标悬停在网页中的元素上

🎬 视频课程：影刀RPA中级课程： 网页自动化-进阶

网页对象

选择一个之前通过【打开网页】或【获取已打开的网页对象】指令创建的网页对象

操作目标

从「元素库」中选择一个已捕获的元素或通过「捕获新元素」来捕获新的网页元素作为操作目标

模拟人工悬停

模拟人工的方式触发悬停事件，待悬停元素被遮挡时可取消勾选

延迟时间(s)

指令执行完成后的等待时间

鼠标悬停位置

中心点：元素矩形区域的中心点

随机位置：自动随机元素矩形区域内的点

自定义：手动指定目标点




等待元素存在(s)

等待目标元素存在的超时时间

使用示例

此流程执行逻辑：打开影刀官网 --> 使用【鼠标悬停在元素上(web)】模拟人工将鼠标移动在指定元素中心点位置 --> 悬停后显示下拉菜单 --> 执行【点击元素(web)】指令点击指定元素
