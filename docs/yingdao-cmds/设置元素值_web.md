# 设置元素值(web)

设置元素值(web)
💡

设置网页元素值，一般是'input'、'select'元素的value

🎬 视频课程：影刀RPA中级课程： 网页自动化-进阶

网页对象

选择一个之前通过【打开网页】或【获取已打开的网页对象】指令创建的网页对象

操作目标

从「元素库」中选择一个已捕获的元素或通过「捕获新元素」来捕获新的网页元素作为操作目标

元素值

设置"input"、"select"等元素的value

等待元素存在(s)

等待目标元素存在的超时时间

使用示例

此流程执行逻辑：打开影刀商城网页 --> 使用【设置元素值(web)】指令设置指定元素的值
