# 运行或打开

运行或打开
💡

!描述：运行软件、打开文件、打开文件夹、打开网址、执行系统命令等

路径或命令

待运行的exe软件的文件完整路径，如："D:\ShadowBot.exe"

待打开的文件完整路径，如："D:\测试文件.txt"

待打开的网址，如："www.yingdao.com"

Windows命令，如：calc (计算器)、control (控制面板)、cmd (命令行) 等

Windows10商店应用URI，如：ms-settings:network-wifi (查看wifi网络)

其他在Win+R运行窗口中可执行的指令

在指令执行之后

继续执行下一条指令

等待主窗口出现

等待应用执行完成

保存执行结果至

保存执行路径或命令后的结果至变量

注：执行结果包含pid (进程唯一标识码)、main_window_handle (主窗口句柄)、exit_code (退出码)

参数(可选)

●参数代表的是option，支持Short option和Long option俩种。
 例如（Short option）：
ls -l 
grep -i

例如（Long option ）：
ls --all 
git --version

●运行exe程序时需要传递的命令行参数，参数格式取决于目标软件。若参数中需要包含一个可能带有空格的路径，可以在路径两段增加英文双引号"来避免空格造成的路径截断问题。

工作目录(可选)

●工作目录指的是exe程序或系统命令运行的目录。

●不填写工作目录，默认运行在影刀安装目录。




以管理员身份运行

指定是否以管理员身份运行目标程序，使用管理员身份打开文件或程序。Windows将会显示一个提示框请求确认是否运行

窗口风格
