# 激活软件窗口

激活软件窗口
💡

激活指定窗口使其在[**前台运行**](https://zhidao.baidu.com/question/367903390.html)

🎬 视频课程：影刀RPA中级课程：桌面软件＋键鼠自动化

获取窗口方式

窗口对象：选择一个之前通过【获取窗口对象】指令创建的窗口对象

捕获窗口元素：获取操作目标所在的窗口对象

窗口标题或类型名：从当前可获取的窗口中选择目标窗口标题及类型名(可选)

窗口句柄：获取指定窗口句柄的窗口对象




使用示例

此流程执行逻辑：使用【激活软件窗口】指令激活指定标题的窗口
