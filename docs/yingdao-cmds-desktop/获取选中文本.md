# 获取选中文本

获取选中文本
💡

获取当前激活窗口中选中的文本

等待时间（毫秒）

若选中文本过程或网络反应较慢可适当延长

保存选中文本至

保存获取到的选中文本为变量

使用示例

此流程执行逻辑：执行【获取窗口对象】指令获取指定窗口 --> 使用【获取选中文本】指令获取选中的文本并保存结果 --> 执行【打印日志】打印保存结果
