rpa_core 指令清单对比

生成日期：2026-09-07。对比参考隔壁仿影刀项目指令库（commands-new.json）。

术语说明
kind（命令类别）
action动作：对外部世界执行一次操作（点击、输入、写入等），通常改变系统状态
query查询：只读获取数据，不改变任何东西
transform变换：纯数据加工（截取、格式化、拼接等），不触碰外部系统
lifecycle生命周期：创建或关闭一个会话资源（浏览器、桌面窗口附着）
effect（副作用等级，决定是否可重试/回放）
pure无副作用：纯计算，无外部副作用，可安全重试/回放
read只读：读取外部状态，不改变它
idempotent-write幂等写入：重复执行结果一致，可安全重试
unsafe-write不可重试写入：重复执行可能多写，禁止自动重试
session会话：创建/关闭会话资源（生命周期类）

输入参数：每条命令执行所需的字段，格式 字段:类型*（* = 必填）。类型取值：string 文本、number/integer 数字、boolean 布尔、object 对象、array<T> 数组。输出：命令执行后返回的字段。

三、对比与推荐新增（适合 rpa_core 零依赖取向）

概览

  • 我们 26 条（browser/data/desktop 三线）。
  • 隔壁 62 条，覆盖 8 个类别。
  • 我们明显少的：条件判断、循环、异常处理（仅 if/forEach/try 三个控制流容器），以及浏览器标签页管理/截图/页面信息、桌面截图/系统信息/等待 等。

推荐新增

建议类别理由复杂度
data.setVar / data.log / data.getCurrentDateTime变量与数据/输出日志流程传参、中间结果、过程可视化，RPA 地基（隔壁已有 setVar/log）低
控制流 while / break / continue条件循环循环提前退出、条件循环，补全表达力（隔壁已有 whileCondition/break/continue）中
browser.takeScreenshot页面RPA 验收/留证刚需，Playwright 原生支持中
browser.newTab / switchTab / closeTab页面多标签页真实场景（隔壁已有 navigate/newTab/switchTab）中
browser.hover元素操作菜单/hover 场景，Playwright hover 原生低
browser.getPageInfo页面调试与断言（URL/标题/元信息）低
desktop.takeScreenshot桌面桌面验收留证；需零依赖截图实现（深挖 stdlib/GDI 成本高）高
desktop.getMousePos / sendKey / 系统信息桌面常见桌面操控，Win32 通道可做中

建议优先级

  1. 先补控制流与变量：data.setVar / data.log / while / break / continue——流程表达力地基，零依赖、成本低。
  2. 再补浏览器实用：takeScreenshot / newTab|switchTab|closeTab / hover / getPageInfo。
  3. 桌面与业务：按真实用例逐条立项（注意第三方库边界）。
