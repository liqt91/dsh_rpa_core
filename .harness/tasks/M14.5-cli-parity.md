# M14.5 CLI 通道对齐

状态：`done`

## 背景与动机

维护者决策（2026-09-03）：能力优先经命令行启动，服务端只承载人类交互、复用能力层（ADR 0006 §6 通道对齐原则）。当前缺口：capture / catalog / elements 仅 devserver 有入口，CLI 没有——agent 通道（M15 WorkBuddy 主路径）无法离线完成捕获→落库全流程。本里程碑补齐 CLI 侧能力，与 devserver 同权。

## 决策

- CLI 与 devserver 同为能力层薄通道：**直接 import 复用**（store / model / capture 包），不 spawn 解析 CLI 输出。
- 元素校验逻辑下沉能力层：`model/capture.py` 新增 `validate_element_document` / `selector_errors` / `ElementDocumentError`，devserver/app.py 改为薄封装。
- `capture` 一次性会话模型：单进程 start → pick（阻塞至用户手势/超时）→ 可选 `--save-as --flow` 落库 → finally cancel+close（规则 11）。
- 落库走 M13.1 目录：`--workflows DIR` 根下 `<flow>/elements/<name>.json`。
