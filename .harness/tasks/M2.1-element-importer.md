# M2.1 旧元素库导入器

状态：`done`

## 目标

将旧版 `elements.json` 数据导入为 rpa_core 的类型化 locator 记录，但不导入或执行同级 `rpa_script` 的任何 runtime 代码。

## 任务

- [x] 将旧版浏览器和桌面元素结构作为静态数据 fixture 盘点。
- [x] 定义类型化 Element Catalog 和来源追踪模型。
- [x] 校验并规范化受支持的 locator candidates。
- [x] 对丢弃、歧义或不支持的字段输出诊断。
- [x] 保留源文件信息和旧元素身份。
- [x] 增加确定性导入 fixture 和契约测试。
- [x] 保证 importer 不参与 runtime executor 路由。

## 验收标准

- [x] Importer 不依赖导入 `rpa_script` Python 模块。
- [x] 不支持的数据绝不静默消失。
- [x] 导入后的浏览器和桌面 locator 满足新类型契约。
- [x] 相同输入重复导入时产生完全相同的输出。
- [x] 完整 harness 门禁通过。
