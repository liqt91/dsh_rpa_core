# M47.1：编辑中预览高亮（C3，M47 通道加 mode）

Status: `done`

Plan: docs/yingdao-gap-catchup.md §C3 / M47 残留 S2

## 目标

编辑选择器时页面上**即时高亮**当前 css 命中的元素（黄框驻留，不是 1.6s 闪烁），
复用 M47 的按需短连接通道：`capture_verify` 信封加 `mode`（`flash` / `preview` /
`clear`），content script 按 mode 决定「闪一下」还是「驻留」还是「清场」。

## 设计要点

- **同一通道三 mode**：`flash` = 原校验（默认，旧信封不标 mode 也走它）；
  `preview` = 黄框驻留（每次预览先清上一轮，count=0 也要清——选择器改到不再命中的
  瞬间旧框必须消失）；`clear` = 只清场（css 可空）。
- **捕获态开闸先清预览框**：armed 广播到达时 content 顺手 `clearVerifyFlash()`
  ——捕获红框下面赖着上一轮的黄框是视觉污染。
- **预览挂在 `ElementEditorForm`**（不是确认框）：确认框与元素库编辑器复用同一份
  编辑区，预览挂在 form 上两边同时受益（M47 校验按钮只在确认框，是因为「校验」
  语义上属于「刚捕获完」；「预览」属于「正在改 css」，两处都在改）。
- **防抖 + 工作线程**：css_edit.textChanged → 500ms 单发 QTimer → 工作线程走通道
  → Qt 信号回主线程更新预览标签；模态 exec 阻塞主线程，绝不能在主线程发网络请求。
- **收场清场**：对话框 finished → 发 `mode:"clear"`（fire-and-forget）；预览框
  不能赖在页面上陪用户关掉编辑器。
- **EXT_BUILD 0.5.0 → 0.6.0**：扩展码改了必须 bump（对账机制存在的意义）。
