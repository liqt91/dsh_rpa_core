# M13.1 流程目录化与元素即流程资产

状态：`done`

## 背景与动机

维护者决策（2026-09-02）：仓库/工作区流程改为**每流程一个目录**，对齐 `examples/<名>/workflow.json` 形态；**捕获元素作为流程资产**随目录入版本库，取代全局平铺 `elements/` 根。运行控制立项结论记 backlog（最小范围），不进入本里程碑。

## 决策（写入 ADR 0007 §2 修订）

- 目录形态：`<workflows_root>/<流程名>/workflow.json`（`WorkflowDirStore`：list 只统计含 workflow.json 的子目录；delete 空目录一并移除）。
- 元素资产：`<流程名>/elements/<元素>.json`（可入版本库）；元素端点嵌套于流程资源 `/api/workflows/{name}/elements[/{element}[/verify]]`。
- capture `pick` 带 `saveAs` 时须同时带 `flow`（缺省 400）。
- 移除全局 `/api/elements*`、`DevServer.elements_root`、CLI `--elements`、仓库根 `elements/` 概念；workflow 名正则/越界/原子写不变，根遗留平铺 `.json` 不再识别。
