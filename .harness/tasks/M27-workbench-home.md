# M27 工作台（首页）+ 编辑器两段式

状态：`done`

关联：ADR 0017（宿主形态三：工作台 + 编辑器）、ADR 0016（GUI 主力形态）、ADR 0011（GUI 不承载 runtime）、
M25（运行历史读取器）、M21/M24（运行控制与调试，控制权在编辑器）
前置：`WorkflowDirStore.list/read`（流程库）、`rpa_core.run_history`（M25）

## 背景与范围

「流程管理」与「运行历史」目前挤在编辑器里（工具栏下拉框 + 底部 dock），流程/历史一多就不可用。
本任务按 ADR 0017 落地**独立工作台窗口（首页）**：

- 工作台：流程列表（状态/最近运行/资产数）+ 运行历史（全局、可筛选）+ 管理动作 + 运行入口；
- 编辑器：保持现有单窗口形态（画布/参数/运行控制/元素库/数据表格/变量）；
- 运行控制（暂停/继续/单步）**只在编辑器**；工作台只「运行 + 看状态」；
- 删除流程 = 提示后连同 `elements/`、`data/` 与**该流程的运行历史**一并删除。

## 风险 / 注意

- **两窗口生命周期**：工作台与编辑器的打开/关闭/刷新联动要定清楚（谁监听谁），避免悬空窗口
  或重复打开同一流程；测试里注意 Qt 窗口未 show 时的可见性语义不可靠（沿用 offscreen 约定）。
- **删除流程**是不可逆操作：提示必须列明连带范围、默认按钮为取消；测试要覆盖「取消不删」。
- **运行控制归属**：工作台不提供暂停/继续（ADR 0017 决策 3），只显示状态并给「在编辑器中打开」，
  避免两个入口控制同一 run。
- 工作台打开编辑器时，编辑器仍需 `workflows_root`（store）才能运行/保存命名流程。
